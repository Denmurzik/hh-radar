Что у этой базы спрашивает агент

Те же цифры, но через MCP: инструменты подключены к Claude Desktop, и на вопрос в свободной форме агент отвечает выборкой из базы, а не догадкой.

  • Какие навыки чаще всего требуют в вакансиях по AI и автоматизации?

    Чаще всего — Python: 63% вакансий (33 шт.). Дальше: Docker, SQL, REST API, PostgreSQL.

  • На какую вилку рассчитывать?

    Средние 50% вакансий с указанной зарплатой лежат между 120 000 ₽ и 205 000 ₽. Вакансии без вилки в расчёт не входят — их в базе заметная доля.

  • Найди вакансии, где нужно чинить чужие сломанные автоматизации.

    Такое не находится по ключевым словам: в объявлениях пишут «поддержка интеграций» и «доработка существующих процессов». Это запрос к semantic_search — поиску по смыслу через pgvector.

Личный проект. Написан для собственного поиска работы: искал вакансии руками, надоело, автоматизировал. Данные на этой странице — демонстрационные: вакансии и работодатели вымышлены и сгенерированы скриптом из репозитория. Настоящая база собирается через официальное API hh.ru с токеном приложения, хранится локально и показывается только агрегатами — чужие объявления в публичном репозитории не лежат.

Курсы валют для приведения зарплат — статичные и приблизительные: точность здесь не нужна, нужна общая шкала для сортировки.
