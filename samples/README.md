# Примеры данных

Четыре вакансии в том формате, в котором их отдаёт API hh.ru. Нужны для
`hh-radar seed` — чтобы можно было посмотреть на работающий поиск и
MCP-инструменты, не заводя токен приложения на dev.hh.ru.

Это те же самые файлы, на которых работают тесты разбора: демо не должно
жить в отдельной кодовой ветке, иначе оно однажды разойдётся с реальностью.

Полноценная база собирается командой `hh-radar ingest` и здесь не лежит —
выгрузки чужих вакансий в публичном репозитории быть не должно.
